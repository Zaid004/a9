# منصة A9 🩺

منصة بسيطة لطلاب مجموعة A9 بكلية الطب. تشتغل بالمتصفح، على الموبايل والحاسبة، وبيها وضع ليلي.

## الأقسام
- **الرئيسية**: محاضرات اليوم، أقرب امتحان مع عداد أيام، والإعلانات (المثبتة تطلع فوق).
- **الجدول**: الجدول الأسبوعي من السبت للخميس، واليوم الحالي يتلون.
- **المحاضرات**: المواد وتحت كل مادة محاضراتها مع رابط الملف. كل طالب يگدر يعلّم ✓ على اللي خلصه ويشوف نسبة تقدمه (تتحفظ بجهازه).
- **الامتحانات**: كل الامتحانات مع كم يوم باقي.
- **بنك الأسئلة**: أسئلة MCQ مع الجواب والشرح، تگدر تختار مادة معينة، وتنحفظ أحسن نتيجة إلك.
- **روابط**: كروب التلگرام، الدرايف، ومواقع مفيدة.

## شلون تعدل المحتوى
كل المحتوى بملف واحد: **`data/data.js`**. افتحه (حتى من موقع GitHub نفسه بزر ✏️) وبدّل الأمثلة بمعلوماتكم:
- إعلان جديد ← ضيفه بقسم `announcements`
- محاضرة جديدة ← ضيفها تحت المادة بـ `lectures` وحط رابط الدرايف/التلگرام بـ `link`
- امتحان ← بقسم `exams`
- سؤال ← بقسم `questions` (رقم `answer` يبدي من 0)

احفظ (Commit) والموقع يتحدث خلال دقيقة.

## شلون تنشره ببلاش (GitHub Pages)
1. ادمج الفرع على `main`.
2. بالريبو روح **Settings → Pages** وبـ **Source** اختار **GitHub Actions**.
3. أول ما ينرفع شي على `main` ينشر الموقع وتطلع لك رابط مثل `https://<اسمك>.github.io/a9/` — دزه لكروب المجموعة.

## تجربة محلية
افتح `index.html` بالمتصفح مباشرة، ما يحتاج شي ثاني.
